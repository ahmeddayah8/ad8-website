AD8 Real Estate Website 🏠

A modern and responsive real estate website built to showcase different types of properties for sale and rent.

The project allows users to explore available properties, view property details, discover real estate agents, and learn more about the company.

🚀 Live Demo

https://ad8-website.vercel.app/

📌 Features

- Modern and responsive user interface
- Property listings
- Property details pages
- Real estate agents section
- Agent profile pages
- About page
- Contact page
- Responsive navigation
- Reusable React components
- Client-side routing with React Router

🛠️ Technologies Used

- React
- Vite
- Tailwind CSS
- React Router
- Lucide React

📂 Pages

- Home
- Properties
- Property Details
- Agents
- Agent Details
- About
- Contact

📱 Responsive Design

The website is designed to work smoothly across different screen sizes, including:

- Mobile devices
- Tablets
- Laptops
- Desktop screens

🎯 Project Purpose

The purpose of this project was to practice and improve my frontend development skills, including:

- Building reusable React components
- Creating responsive layouts
- Working with React Router
- Organizing a React project structure
- Designing a modern user interface
